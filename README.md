# dsh-superagent-demo

Demo repository for trying DeepSeek dsh-superagent.

Mention the agent account in an Issue or comment to give it work.

## 使用说明

1. 在本仓库新建 Issue，写清需求，并用 `@shark-agent` 提及机器人账号。
2. 也可以在已有 Issue 或 PR 的评论中 `@shark-agent` 追加需求。
3. 机器人会领取任务，在独立分支上完成改动，并通过 Pull Request（PR）交付，不会直接修改 `main`。
4. 在 PR 中查看改动和验证说明、参与讨论，确认无误后由维护者合并。
